FAIZU&AFIN – Cloudflare Pages പതിപ്പ്

ഈ ZIP Cloudflare Pages + Pages Functions + D1 ഉപയോഗിക്കുന്ന രീതിയിൽ ക്രമീകരിച്ചതാണ്.

പ്രധാനമായി:
- dist/ ൽ വെബ്സൈറ്റിന്റെ ഫയലുകൾ ഉണ്ട്.
- functions/api/ ൽ Login, Signup, Logout, Chat API routes ഉണ്ട്.
- migrations/ ൽ D1 database schema ഉണ്ട്.
- wrangler.toml Cloudflare ക്രമീകരണമാണ്.

ഇത് നേരിട്ട് Dashboard-ലെ static drag-and-drop upload മാത്രം ചെയ്താൽ backend പ്രവർത്തിക്കില്ല. താഴെയുള്ള Wrangler രീതിയാണ് ഉപയോഗിക്കേണ്ടത്.
